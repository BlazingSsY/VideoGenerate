# 画布运行与观看视频

- 生成节点上的「运行」只运行当前节点；「重新生成」会重新提交该镜头。
- 画布左上角回撤按钮旁的「一键运行画布」先保存编辑，再生成新增、失败、结果已过期或输入有修改的节点，包括未接入输出的节点。输入未变且已有成功结果的节点直接复用，不重复提交生成任务。
- 复用同时检查实际提示词、模型参数、素材顺序与上游参考视频。修改上游输入或重新生成上游视频后，依赖它的镜头也会更新；移动节点、调整输出片段顺序只影响布局或拼接。单独运行过的生成节点也支持复用。
- 已有结果只有在线地址或本地文件丢失时，先下载已有视频供拼接；下载失败会提示错误，不自动重新生成并产生费用。
- 独立镜头按 `AGENT_RUN_CONCURRENCY` 限制并发（默认 2）；生成节点之间的视频参考连线会形成依赖，使用本轮上游的视频结果。
- 输出节点在所需镜头完成后自动拼接。多个输出节点分别执行各自的拼接计划；顺序、转场及移除的片段以输出节点设置为准。
- 没有输出节点时，界面自动创建一个，将所有生成节点按从上到下、同一行从左到右的顺序接入。已有输出节点未连接片段时，会提示先完成连线。
- 每个生成节点和输出节点都有内嵌播放器及「观看视频」大图播放入口。观看已有视频不会重新生成或拼接；需要更新输出时点击「重新合成」。
- 运行进度和输入快照保存在数据库中，刷新页面可继续查看。移动节点不影响结果回填；修改输入后，旧运行的结果不会覆盖新编辑。
- 单个镜头失败不会阻止其他独立镜头完成；依赖失败镜头的输出节点会显示错误。成功的视频仍可观看。再次点击「一键运行画布」会复用未修改的成功镜头，重新执行失败或有修改的镜头，并按当前顺序重新拼接。

## 接口

- `POST /api/canvases/{id}/run`：请求体 `{"revision": 当前画布版本}`，返回持久化运行及任务状态。
- `GET /api/canvases/{id}/runs/latest`：最近一轮运行，供页面恢复和轮询。
- `POST /api/canvases/{id}/nodes/{node_id}/run`：单节点运行。
- `POST /api/canvases/{id}/output/{node_id}/compose`：按已保存的片段顺序手动合成，结果持久化到输出节点。
- `GET /api/canvases/{id}/status`：节点状态、错误及带签名的播放地址。

运行复用现有 AgentRun/AgentTask 执行调度，直接从画布生成任务快照，不调用语言模型规划。开始前检查权限、参数、画布版本及重复运行；自动拼接需要 FFmpeg，任务会将生成片段下载到本地供拼接使用。

## 素材引用与排序

- 「参考生视频」节点的「素材引用」面板列出每份图片、视频、音频的文件名和发送编号，各类型独立编号。
- 点击 `{{图片1}}`、`{{视频1}}`、`{{音频1}}` 等固定引用，可插入附加提示词；也可在连接的提示词节点中使用。为素材填写用途，例如「主角外观」「镜头运动」「对白声音」，会将用途说明一同发送。
- 上下按钮调整同类素材的发送顺序。固定引用仍绑定原来的连线，例如图片1下移后，`{{图片1}}` 会转换为「图 2」。建议通过固定引用编写提示词，避免直接写入随排序变化的发送编号。
- Wan 使用「图 1 / 视频 1 / 音频 1」；HappyHorse 使用 `[Image 1]`。MiniMax 未公布专用引用标记，使用「第 1 张参考图片 / 第 1 段参考视频 / 第 1 段参考音频」及用途说明表达对应关系。
- 「查看实际发送的提示词」可检查转换结果。引用素材断开后会显示提示并拒绝运行，避免原引用指向新素材。重新连接后请插入新的引用。
- 单节点运行与「一键运行画布」共用引用转换；启动时同时冻结提示词和媒体顺序，后续修改不会改变在途任务。
- 打开旧画布或移动节点保持原生成输入。首次插入固定引用、设置用途或调整素材顺序时才启用引用设置；启用后，连接的提示词和节点的附加提示词会一起发送。请求内的媒体与提示词编号保持对应，模型对内容和用途的遵循仍由其能力决定。

## 画布交互

- 最终输出节点通过拖动片段行调整拼接顺序，右侧仅保留删除按钮。删除片段会同时移除它连接到当前输出的连线，保留生成节点及其他连接；重新连接可再次加入。拖动时显示跟随鼠标的半透明片段卡片，与原片段行保持相同尺寸并随画布缩放；落点高亮，按 Escape 可取消。转场跟随原片段，保存后刷新保留顺序。
- 鼠标移到左侧「添加节点」图标会直接展开菜单，移走后收起；点击也可展开。悬停设置开关已移除，工具栏图标即时高亮。
- 主题开关位于右上角账户入口左侧，月亮为深色、太阳为浅色，点击或聚焦后按空格切换。深色连线保留原有三层渐变流光；浅色也使用主线、中层发光与外层晕染，以低饱和的蓝、紫、青等渐变色适配浅色背景。
